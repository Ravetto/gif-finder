# 🔍 Gif Finder App

Aplicación web desarrollada en React para buscar y explorar GIFs en tiempo real.

🚀 *[Ver Demo en Vivo](https://ravetto-gif-finder.netlify.app/)* 

---

## ⚡ Características Principales

* *Búsqueda en tiempo real:* Conexión con la API de Giphy.
* *Caché eficiente:* Implementación del hook useRef para guardar búsquedas anteriores y no repetir consultas HTTP a la API.
* *Testing Unitario:* Pruebas de componentes y lógica con cobertura de tests (>80%).
* *CI/CD Integrado:* Despliegue automático en la nube mediante Netlify vinculado a GitHub.

---

## 🛠️ Tecnologías Utilizadas

* *Framework:* React 18
* *Lenguaje:* TypeScript
* *Herramienta de Build:* Vite
* *Testing:* Vitest + React Testing Library
* *Estilos:* CSS3
* *Hosting:* Netlify
